\# Flappy Bird 🐦



Простая копия игры Flappy Bird на Python с использованием библиотеки Pygame.



\## 🎮 Как играть



\- Нажми \*\*ПРОБЕЛ\*\*, чтобы начать игру.

\- Нажимай \*\*ПРОБЕЛ\*\*, чтобы птица подпрыгивала.

\- Пролетай между трубами и набирай очки.

\- Если птица столкнётся с трубой или упадёт — игра заканчивается.

\- После проигрыша нажми \*\*ПРОБЕЛ\*\*, чтобы начать заново.
